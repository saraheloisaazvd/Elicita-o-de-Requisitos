Pergunta de empatia:

Por que eu acabo deixando trabalhos da faculdade para a última hora, mesmo sabendo que tenho vários dias para fazê-los?

Definição:

Eu não deixo as atividades para a última hora por falta de interesse, mas porque tenho dificuldade em visualizar quanto tempo ainda tenho até cada prazo e acabo priorizando apenas as tarefas mais urgentes.

Ideias:
Uma lista de atividades mostrando o prazo restante e o nível de urgência de cada tarefa;
Um sistema de lembretes que avise o aluno alguns dias antes do prazo;
Uma plataforma acadêmica que permita cadastrar trabalhos e provas, organizar as tarefas por prioridade e acompanhar o tempo restante para cada entrega.
Ideia Escolhida: 3
História de Usuário:
Como aluno, quero cadastrar trabalhos e provas com suas respectivas datas, para conseguir acompanhar os prazos das atividades acadêmicas;
Como aluno, quero visualizar minhas atividades organizadas por prioridade e prazo, para saber qual tarefa devo realizar primeiro;
Como aluno, quero receber lembretes antes das datas de entrega, para evitar esquecer ou deixar as atividades para o último momento.
Critérios de aceitação:
Dado que o aluno cadastrou uma atividade com uma data de entrega, quando o prazo estiver próximo, então o sistema deve enviar um lembrete informando a atividade e sua data de entrega;
Dado que o aluno possui várias atividades cadastradas, quando acessar a lista de tarefas, então o sistema deve apresentar as atividades organizadas conforme prioridade e proximidade do prazo;
Dado que uma atividade possui uma data de entrega cadastrada, quando o aluno acessar a plataforma, então o sistema deve exibir quantos dias faltam para a entrega.
